# S.K. Marbles — GitHub Demo Website

Premium, responsive single-page demo website for S.K. Marbles, Liluah, Howrah.

## Folder structure

Everything is intentionally kept in **one single folder**. There are no asset subfolders.

- `index.html`
- `style.css`
- `script.js`
- `sk.webp`
- `showroom.webp`
- `marble-collection.webp`
- `tiles.webp`
- `granite.webp`
- `showroom-detail.webp`

## GitHub Pages

1. Create a GitHub repository.
2. Upload all files from this folder directly into the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch** and choose the `main` branch and `/ (root)`.
5. Save.

No build process or framework is required.
